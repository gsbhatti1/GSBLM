# Sprint 8: No-Thinking Mode

## Goal

Reduce thinking for tired users.

LifeMode should feel like:

```text
I got you. Start here.
```

not:

```text
Here is a powerful extension.
```

## Added

- cross-page journey memory
- better stuck menu
- human-help triage
- Read this step
- Save and stop for today
- checkpoint saved messages
- Show advanced tools wording
- helper packet copy
- safer sign-in stuck messaging

## Product rule

The user should not need to understand tabs, tools, or journeys first. The first experience is one path and one next step.

## Memory rule

Journey memory stores only:

- goal
- step number
- timestamp

It does not store form answers, page text, VA login, ID.me login, SSN, claim number, or document contents.

## Human rule

When the user says "I am stuck," do not dead-end them. Ask what kind of stuck.
