# Demo Recording Checklist

## Before recording

- Use Chrome.
- Load extension from `C:\Dev\GSBLM\extension`.
- Reload extension after pulling latest code.
- Pin LifeMode in toolbar.
- Use a clean browser window.
- Zoom browser to 100%.
- Close unrelated tabs.
- Open `https://www.va.gov`.
- Keep local demo pages ready.

## Record these scenes

1. LifeMode icon opens panel directly.
2. Task Portal detection on VA.gov.
3. Link badges on page.
4. Start first step.
5. Go button highlights a target.
6. Companion explains page.
7. Application Check on demo form.
8. Memory note saves.
9. Copy handoff.
10. Human Help tab.
11. Local ZIP search.
12. Refresh persistence.
13. Close stops refresh reopen.

## Do not show

- private medical records
- private claims
- real personal forms
- passwords
- social security numbers
- real VA account screens

## Final line

LifeMode does not replace humans. It helps people reach the next step and the right human.
