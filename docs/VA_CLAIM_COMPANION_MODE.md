# VA Claim Companion Mode

## Purpose

VA Claim Companion Mode helps Veterans organize, understand, and prepare claim-related tasks without pretending to be a VSO, attorney, claims agent, doctor, or rating expert.

## Core promise

LifeMode will not file the claim for the user. It will help the user avoid getting lost, organize missing pieces, prepare questions, write clear truthful notes, and reach an accredited human helper.

## Mode features

- claim page detection
- evidence checklist
- condition list
- symptom impact note
- service event note
- treatment records checklist
- buddy statement outline
- C&P exam prep
- VSO handoff
- deadline memory
- missing item check

## Never do

- never promise approval
- never suggest a rating
- never tell a Veteran to exaggerate
- never hide facts
- never replace accredited help
- never submit without user control

## Companion prompts

- What condition are you working on?
- What part of the process are you stuck on?
- Do you have VA medical records?
- Do you have private medical records?
- Do you have a DD214 or service records?
- Do you have supporting statements?
- How does this affect daily life?
- Do you want questions to bring to a VSO?

## Human routing

Always include:

- Find VSO / accredited representative
- VA Social Work
- Veterans Crisis Line
- Trusted person handoff
