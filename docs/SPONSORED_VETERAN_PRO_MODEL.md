# Sponsored Veteran Pro Model

## Company law

LifeMode Veteran is free for Veterans. 100%.

No Veteran pays for the bridge back to help.

## Why

The Veteran is not the revenue target. The Veteran is the reason.

## Funding paths

- nonprofits
- county veteran offices
- clinics
- grants
- employers
- donors
- universities
- health systems
- organization plans
- civilian Pro plans

## Free for Veterans

- steps
- focus mode
- read aloud
- memory note
- copy handoff
- human help routing
- local help routing
- basic Application Check
- Veteran Help tab
- basic Companion guidance

## Sponsored Pro

- saved workflows
- document checklist binder
- VA Claim Companion Mode
- description drafting
- appointment prep
- VSO handoff packets
- caregiver/trusted helper sharing
- reminders
- advanced Application Check

## Organization plan

Organizations pay for:

- custom workflows
- install support
- training material
- non-sensitive analytics
- partner landing pages
- admin dashboard later
- accessibility reports
- sponsored seats

## Donation story

A donation does not buy an app. It buys one more bridge between a person and the help they could not reach alone.
