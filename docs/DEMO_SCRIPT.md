# LifeMode Demo Script

Use this script when showing the prototype to someone.

## 30-second story

LifeMode is for the moment when a person knows what they need to do, but the page is too much.

It turns a confusing page, form, portal, or document into a calm checklist and one clear next step.

## Demo setup

1. Load the Chrome extension from the `extension` folder.
2. Open `demo/test-form.html` in Chrome or open a real article/form page.
3. Click the LifeMode extension icon.
4. Click **Open LifeMode**.

## Demo flow

### 1. Open LifeMode

Say:

> LifeMode opens on top of the page where the person is already stuck. No account. No dashboard first.

Show:

- overlay panel
- page type badge
- calm summary
- next step card

### 2. Refresh checklist

Click **Refresh checklist**.

Say:

> LifeMode scans the page and turns it into a short list of useful steps.

Show:

- Form Rescue on forms
- Reading Mode on articles
- Page Rescue on general pages

### 3. Start first step

Click **Start first step**.

Say:

> It does not just summarize. It points the person to the actual part of the page they should handle next.

Show:

- page scrolls
- target area highlights

### 4. Check off steps

Check the first item.

Say:

> When the user finishes one thing, LifeMode moves the next step forward.

Show:

- checked item
- updated next step

### 5. Focus mode

Click **Focus mode**.

Say:

> Focus mode lowers visual noise and stops motion so the page feels less aggressive.

### 6. Read aloud

Click **Read aloud**, then **Stop reading**.

Say:

> For people who are tired, foggy, or overloaded, listening can be easier than reading.

### 7. Memory note

Type a note:

> Come back and upload ID tomorrow.

Click **Save note**.

Say:

> LifeMode can hold a small memory note locally in the browser so the person does not lose the thread.

### 8. Copy handoff

Click **Copy handoff**.

Say:

> If the person needs help, they can copy a clean handoff to a spouse, caregiver, case worker, coach, or trusted person.

## Strong closing

Say:

> This is not a therapy chatbot. It is a daily-life support layer. The win is simple: someone who was stuck completes one real step.

## Demo success sentence

The prototype is working if someone says:

> I know what to do next now.
