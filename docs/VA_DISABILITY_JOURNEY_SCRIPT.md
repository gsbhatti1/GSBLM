# VA Disability Journey Script

## User says

I need to apply for VA disability.

## Companion response

I can walk with you through the official VA path.

We will not do everything at once.

1. Start with the official VA disability claim page.
2. Sign in only on VA.gov.
3. LifeMode will stay in Private VA Mode.
4. We will build an evidence checklist.
5. We can write a plain description from your rough notes.
6. We can prepare questions for a VSO or accredited representative.

## Action buttons

- Open VA disability claim page
- Open online application
- Find free VSO help
- Prepare evidence checklist

You are on VA.gov. Private VA Mode is on.
